# Offline Games Collection

Simple offline games for quick fun.

## 1. Dino Jump (Python)
A recreation of the classic "No Internet" browser game. 
- **Goal:** Jump over obstacles and survive as long as possible.
- **Visuals:** Minimalist white and grey design.
- **Features:** Dynamic score counter and cactus generation.
- **Controls:** Space to jump.

## 2. B&W Snake (Rust)
Classic Snake game built with performance and simplicity in mind.
- **Grid:** 20x20 play area.
- **Mechanics:** Eat round pellets to grow. The game ends if the snake hits the wall or itself.
- **Visuals:** Pure Black & White (Retro style).
- **Controls:** Arrow keys for movement.

---

### Installation

**Dino Jump:**
1. Install Python 3.x
2. pip install pygame`
3. python dino.py`

**Snake:**
1. Install Rust (cargo)
2. Run cargo run inside the snake directory.
